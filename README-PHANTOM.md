# Project Phantom – Android Voice Demo

Standalone proof-of-concept Android demo. It is not connected to AUTAVIQ or Vercel.

## Demo flow

HOUSE → BUS STOP → BUS → WORK → HOME

Tap **Start mic**, grant microphone permission, and speak naturally. Android on-device recognition is preferred when available; the system recogniser is used as fallback. Back, Next and Reset are always available.

Long-press **Project Phantom** to reveal debug information.
